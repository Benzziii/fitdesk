🔥 3 Pilar Ilmiah Memangkas Lemak Visceral (Perut Buncit)

Studi Harvard Health: Visceral Fat

1. Kombinasi Dumbbell Tempo + Zone 2 Walk

Menurut riset Harvard Health dan meta-analisis PMC, sit-up saja tidak membakar lemak perut. Lemak rongga perut (visceral fat) paling cepat menyusut saat latihan beban otot besar (Senin–Jumat) dikombinasikan dengan jalan cepat Zone 2 (Rabu) dan tidur malam 7 jam.

2. Kunci Korset Dalam (Transversus Abdominis)

Pekerja yang duduk 9 jam sering mengalami perut tampak buncit ke depan karena melemahnya otot dinding perut dalam (transversus abdominis) dan panggul miring ke depan (anterior pelvic tilt). Gerakan Stomach Vacuum, Reverse Crunch to Dead Bug, dan Plank menarik dinding perut kembali rata.

3. Defisit 350 kkal & Target Lingkar Perut < 82 cm

Standar klinis Mayo Clinic & WHO menetapkan batas aman lingkar perut pria Asia di < 90 cm, dan untuk tampilan perut rata atletis (proper & ideal) berada di kisaran 78–82 cm (rasio lingkar perut dibagi tinggi badan < 0,48).

💺 Protokol Micro-Break Duduk 9 Jam

Duduk 9 jam membuat otot hip flexor memendek dan menarik panggul ke depan (anterior pelvic tilt), yang menyebabkan perut bawah tampak semakin menonjol/buncit serta memicu sakit pinggang. Berdasarkan panduan Mayo Clinic Office Ergonomics:

  • Aturan 60-2: Setiap 60 menit duduk di depan komputer, berdiri 2 menit sambil mengencangkan otot perut dan bokong (glute squeeze).
  • Seated Thoracic Extension: Satukan tangan di belakang kepala, buka siku lebar, dan busungkan dada ke atas selama 15 detik (Mayo Clinic Desk Stretches).
  • Seated Stomach Vacuum: Saat duduk rapat/mengetik, tarik pusar ke dalam selama 20 detik × 3 kali untuk melatih otot perut dalam.

import os, sqlite3
from datetime import datetime
from dotenv import load_dotenv
from flask import Flask, jsonify, render_template, request

load_dotenv()
app = Flask(__name__)

# Koneksi Otomatis ke Supabase PostgreSQL jika SUPABASE_URL & SUPABASE_KEY diset di Vercel
SUPABASE_URL = os.environ.get("SUPABASE_URL", "").strip()
SUPABASE_KEY = os.environ.get("SUPABASE_KEY", "").strip()
supabase_client = None
if SUPABASE_URL and SUPABASE_KEY:
    from supabase import create_client
    supabase_client = create_client(SUPABASE_URL, SUPABASE_KEY)

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/api/workouts", methods=["GET", "POST"])
def handle_workouts():
    if request.method == "POST":
        data = request.get_json() or {}
        duration_min = int(data.get("duration_min", 35))
        avg_weight_kg = float(data.get("avg_weight_kg", 6.0))
        total_reps = int(data.get("total_reps", 210))
        day_key = data.get("day_key", "senin")
        record = {
            "date": data.get("date") or datetime.now().strftime("%Y-%m-%d"),
            "day_key": day_key,
            "focus_area": data.get("focus_area", "Latihan Harian"),
            "duration_min": duration_min,
            "avg_weight_kg": avg_weight_kg,
            "total_sets": int(data.get("total_sets", 15)),
            "total_reps": total_reps,
            "total_volume_kg": 0.0 if day_key == "rabu" else round(avg_weight_kg * total_reps, 1),
            "calories_burned": int(round(((4.8 if day_key == "rabu" else 5.5) * 3.5 * 71.0 / 200.0) * duration_min)),
            "rpe": int(data.get("rpe", 7)),
            "avg_hr": int(data.get("avg_hr", 124)),
            "notes": data.get("notes", "")
        }
        if supabase_client:
            res = supabase_client.table("workout_logs").insert(record).execute()
            return jsonify({"status": "success", "storage": "supabase", "data": res.data}), 201
    if supabase_client:
        res = supabase_client.table("workout_logs").select("*").order("date", desc=True).execute()
        return jsonify(res.data)
    return jsonify([])

@app.route("/api/weights", methods=["GET", "POST"])
def handle_weights():
    if request.method == "POST":
        data = request.get_json() or {}
        record = {
            "date": data.get("date") or datetime.now().strftime("%Y-%m-%d"),
            "weight_kg": float(data.get("weight_kg", 70.5)),
            "waist_cm": float(data.get("waist_cm", 82.0)),
            "sleep_hrs": float(data.get("sleep_hrs", 7.0)),
            "notes": data.get("notes", "")
        }
        if supabase_client:
            res = supabase_client.table("weight_logs").insert(record).execute()
            return jsonify({"status": "success", "storage": "supabase", "data": res.data}), 201
    if supabase_client:
        res = supabase_client.table("weight_logs").select("*").order("date", desc=False).execute()
        return jsonify(res.data)
    return jsonify([])

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, debug=True)
